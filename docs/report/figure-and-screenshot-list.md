## Section 3 — Dashboard Screenshots

These screenshots must be captured by hand with the live system running. They cannot be generated automatically.

### How to run the system for screenshots

**Terminal 1 — backend:**
```bash
cd backend
source venv/bin/activate   # or .\venv\Scripts\Activate.ps1 on Windows
python app.py
# Confirm: http://localhost:5000/api/health → {"status": "ok"}
```

**Terminal 2 — frontend:**
```bash
cd frontend
npx ng serve
# Open: http://localhost:4200
```

**Browser setup:** open Chrome at `http://localhost:4200`. For consistent capture width, open DevTools (`F12`), enable device mode, and set the viewport to 1440 × 900. A full-page screenshot extension (e.g. GoFullPage) is recommended for views taller than the viewport.

Save screenshots to `docs/report/figures/screenshots/`.
